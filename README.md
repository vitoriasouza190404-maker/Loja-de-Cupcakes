# Loja-de-Cupcakes
Loja virtual de cupcakes gourmet — Projeto Integrador II

Loja de Cupcakes 🧁

Projeto Integrador Transdisciplinar em Engenharia de Software II

Este repositório contém a documentação e o código-fonte do projeto de desenvolvimento de uma loja virtual de cupcakes gourmet.

O sistema tem como objetivo permitir que clientes visualizem produtos, realizem pedidos, selecionem formas de pagamento simuladas e acompanhem suas compras.

O projeto contempla levantamento de requisitos, modelagem de banco de dados, desenvolvimento front-end e back-end, testes de software e documentação técnica.

Status: Em desenvolvimento.
